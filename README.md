# ScholarlySources
An academic journal aggregator to help you find peer-reviewed answers to your questions.

## Use Case
- Need peer-reviewed papers to research/compare 
  
### Data Origin  
Data comes from 3 links to arxiv query results pulled using ayncio, each with a max of 10 article results. There are plans to make this larger and more configurable.
