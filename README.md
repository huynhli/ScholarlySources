# ScholarlySources
An academic journal aggregator to help you find peer-reviewed answers to your questions.

## Use Case
use async to concurrently pull papers from arxiv urls, parse them into Project objects, and save to papers.json
  
### Data Origin  
Data comes from 3 links to arxiv query results, each with a max of 10 article results. There are plans to make this larger and more configurable.
